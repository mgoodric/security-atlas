- **fix(api): a late exception Activate or Revoke no longer panics the server's shutdown drain (#2748).** When `srv.Shutdown` hit its 5 s deadline, a handler still running could start an exception re-evaluation and call `WaitGroup.Add` while `RunHTTP` was inside `Wait`, which `sync.WaitGroup` forbids. The server's background group now closes before it waits, under a mutex, so work started after that runs untracked and is logged instead of joining the group. The drain error `RunHTTP` returns is still printed by `cmd/atlas` before it exits non-zero.
