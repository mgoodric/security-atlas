- **feat(risks): risks carry the organisation's own risk ID (#2838).** A risk has an optional `external_ref` ("R-014"), unique within the tenant when set, ignoring case ("r-014" collides with "R-014"; the typed case is kept). `POST /v1/risks` sets it, `PATCH /v1/risks/{id}` changes or clears it (audited as `fields_changed`, and recorded on the `created` row when set at creation), and a duplicate is a 409 with code `external_ref_taken`. The risk page shows it beside the title, the create and edit form has a "Risk ID" field, and the risk export (CSV, JSON, XLSX) appends an `external_ref` column. Migration `20261278000000_risks_external_ref` adds the column and a partial unique index on `(tenant_id, lower(external_ref))`.
