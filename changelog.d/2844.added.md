- **feat(risks): a risk import maps category and theme values once per batch (#2844).** The batch read (`GET /v1/risks/imports/{id}`) lists `category_values` and `theme_values`: each distinct value of the file (values differing only in case are one value), with the category slug or theme name it maps to. A value that already names an active category (by slug or name) or a theme is mapped at upload. `PUT /v1/risks/imports/{id}/values` maps a value to an existing category or theme, clears its mapping, or, for a tenant approver only, creates the category or theme for it through the audited creation; nothing is created implicitly. A themes column (`Themes`, `Theme`, the export's `themes`) is read, split on commas and semicolons. At approval a row takes the mapped category and themes, and a row with an unmapped value is rejected with those values as the reason. An unknown category is no longer rejected at upload.
