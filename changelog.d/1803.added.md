- **feat(mappingoverlay): overlay edges carry over to a new framework version (#1803).** Approving a carried-over requirement (`exact_code`) in the framework-version migration queue now copies each tenant's active overlay edges to the new version's requirement, in that tenant, active immediately, with a `carry_over` entry in the overlay audit log per copy. Retired edges and requirements new in the version get none, and edges on the old version are untouched. The decision response reports `overlay_edges_copied`.
