- **feat(controls): the controls list filters, sorts and pages on the server (#2131).** `GET /v1/controls?include=state` takes `result`, `freshness`, `owner` (a user id, or `none`), `family`, `framework`, `anchor_fit` and `scope`, and `sort=[-]scf_id|name|family|state|freshness|last_observed_at|owner|frameworks`. Its `total` counts the filtered set. The default order is failing controls first, then the stalest evidence. `/controls` asks for the one page it shows, every column header sorts, and the Owner filter offers "Unowned". Saved views keep working and also save the owner filter and the sort. The State filter now offers the states controls actually report (Inconclusive and Not applicable replace two options that never matched a control), and Freshness gains "No evidence". The SCF catalog view filters by scope and "Has control" only.
