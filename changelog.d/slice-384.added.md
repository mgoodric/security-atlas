- **feat(risk): slice 384 — ActionPlan primitive (schema + CRUD + risk/control linkage).** A fourth first-class risk-register primitive: a forward-looking remediation commitment with an owner, a due date, a free-text triggering event, and many-to-many linkage to the risks and controls a gap touches. Distinct from Exception (a backward-looking, time-bounded waiver) and DecisionLog (an operational tradeoff record). Lifecycle is its own state machine — `draft → in_progress → blocked → completed → verified` (`verified` terminal; no edge back to `draft`) — validated at both the handler layer and a DB transition trigger. New schema: four tenant-scoped tables (`action_plans`, `action_plan_risks`, `action_plan_controls`, `action_plan_audit_log`) with four-policy RLS under FORCE ROW LEVEL SECURITY (the M2M tables use subquery-based RLS against `action_plans.tenant_id` layered on a cross-tenant-safe composite FK); the audit log is append-only by both RLS construction and an explicit `BEFORE UPDATE OR DELETE` trigger. Every mutation writes one audit-log row in the same transaction; deletes are soft (`tombstoned_at`, never hard). New HTTP surface under `/v1/action-plans`: 5 CRUD endpoints + 4 M2M linkage endpoints (cross-tenant or absent targets return 404; per-plan caps of 50 risks + 50 controls return 422 `limit_exceeded`; `due_date` beyond 5 years returns 400), plus read-only `GET /v1/risks/{id}/action-plans` and `GET /v1/controls/{id}/action-plans`. Reuses the existing `risk_register:read`/`risk_register:write` roles — no new authz role. New UI: an `/action-plans` list (status filter + table), an `/action-plans/[id]` detail view, an `/action-plans/new` creation form with searchable risk + control multi-selects (max 50 each), and a read-only "Linked Action Plans" section on the risk and control detail pages. Audit-period-freezing snapshot semantics are honored on the list/snapshot read path (only plans with `created_at ≤ frozen_at` appear in a frozen period's snapshot); deeper period-snapshot integration is deferred to a follow-up slice.
