- **feat(mapping-overlays): an overlay edge's author reads as a name, not a credential id (#2286).** The overlay list and write responses carry `created_by_name` and `retired_by_name`, the coverage and traversal wires carry `overlay.created_by_name`, and the "org mapping" entry shows it. A user reads as their display name, an API key as "API key …" plus the last four characters of its id, `system` as "System", and anything else, including another tenant's user or key, as "Unknown". Names are resolved on the server from the caller tenant's people under RLS. The CSV export's `created_by` and `retired_by` columns are now the names; new `created_by_id` and `retired_by_id` columns keep the recorded ids for audit. A signed-in user's new overlay writes record their user id rather than the per-session credential id; edges written before this change by a session keep that id and read "Unknown".
