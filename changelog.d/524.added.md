- **feat(connectors): slice 653 — Kubernetes PSS collector `metadata.continue` cursor pagination.** The `atlas-k8s` Pod Security Admission collector (`connectors/k8s/internal/pss`) still issued a single `?limit=500` namespace-list GET and consumed only the first page, silently truncating the PSS-admission posture of a cluster with more than 500 namespaces. It now routes its namespace list through the shared read-only paginating reader (`connectors/k8s/internal/k8slist`, `ListAll[apiNamespace]`) added in slice 621, following the Kubernetes `metadata.continue` cursor to completion (bounded by `k8slist.MaxListPages` + the run timeout) — the fourth and final atlas-k8s collector to adopt the shared reader, with no fourth copy of the paginating logic. The collector's duplicated `getJSON` / `APIError` / `drain` are deleted; `pss.APIError` is re-exported as a type alias of `k8slist.APIError` so existing callers are unaffected. **No new ClusterRole grant — still `get,list` only on namespaces (`k8sauth.DocumentedClusterRole` unchanged); push-only wire, the `k8s.pod_security_admission.v1` evidence-kind shape, and the PSS label-only over-collection guard are all unchanged.** Parent: slice 621 (and #524).
