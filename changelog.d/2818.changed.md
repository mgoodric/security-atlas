- **feat(eval): each evidence query sees only the records of its declared `evidence_kind` (#2818).** The engine used to hand every query all of the control's in-window records, whatever their kind, so a query that reads payload fields could misread another kind's records (ADR 0028 decision 5). A query that declares no kind keeps the old behaviour; bundle upload and `atlas-cli controls validate` now warn on it. Control-bundle test fixtures accept an optional `evidence_kind` per record. Stock results change only where a query was reading another kind's records: a two-query control (cc1_4, p4_2) that has only `na` records of one of its kinds is now `inconclusive`, and a record of a kind no query declares no longer counts toward any query. See `docs/audit-log/2818-per-query-evidence-kind-decisions.md`.
