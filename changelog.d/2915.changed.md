- **feat(okta, needs-attention): the Okta connector reads every page, and a long-inconclusive control has a signal (#2915).** Every Okta list call (MFA policies, groups, apps, app groups, policy rules, users, factors) now follows the `Link: rel="next"` cursor until it runs out. Before, only the first page was read, so an Everyone policy on page two could fail cc6_1 when it should pass. A next link to another host is refused, and a listing stops at 1,000 pages. `GET /v1/controls/{id}/state` now gives each inconclusive cell an `inconclusive_since`. The control page shows "Inconclusive since <date>", and needs-attention has a new `inconclusive` band for controls that have been inconclusive for 7 days or more. cc6_1's description now says that PIV and smart-card authenticators (`smart_card_idp`) are not counted.
