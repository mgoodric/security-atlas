- **feat(a11y): slice 361 — global-search combobox ARIA wiring (WCAG 4.1.2).** The global ⌘K search at `web/components/shell/global-search.tsx` is now wired as a WAI-ARIA 1.2 combobox-listbox: the input carries `role="combobox"` + `aria-haspopup="listbox"` + `aria-expanded` (flips on popover open/close) + `aria-controls="global-search-listbox"` + `aria-activedescendant` (resolves to the active row's stable id) + `aria-autocomplete="list"`; the listbox container carries `id="global-search-listbox"` + `aria-label="Search results"`; each result row carries `id="global-search-option-{type}-{id}"` so the input's `aria-activedescendant` programmatically names the highlighted row. A visually-hidden `aria-live="polite"` region (`role="status"` + `aria-atomic="true"`) outside the listbox announces the result count whenever it updates — `"No results"` / `"1 result"` / `"{N} results"` — closing the WCAG 4.1.3 Status Messages gap so SR users hear count without focusing into the popover. **Path 1 (Link-keep) chosen over Path 2 (canonical `<li role="option">`):** preserves `<Link>`'s native cmd-click / right-click semantics, honors P0-361-1 (no interaction shape change), and WAI-ARIA does not forbid `role="option"` on a focusable interactive descendant in one-shot popover usage.
