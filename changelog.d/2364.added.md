- **feat(catalog): crosswalk-edge remap proposals, super-admin only (#1777).** `catalog import-scf` now also queues every live catalog crosswalk edge left on an older SCF release's anchor in `scf_edge_remap_proposals`. Each is classified with the same lineage rule as control proposals (`scfimport.ClassifyLineage`), and the import prints the counts per class. A super-admin decides them at `/v1/admin/crosswalk-edge-remap-proposals`: list, approve, reject, keep-legacy, or approve-unchanged. Approval copies the edge onto the chosen anchor in the target release with the same relationship, strength, rationale, source attribution and mapping tier, and leaves the legacy edge untouched. Every decision appends to `scf_edge_remap_decisions`. The gate is in OPA (`super_admin.rego`, excluded from admin's and grc_engineer's blanket allows) and in the handler. In the database the app role can only read the queue and call `scf_edge_remap_decide()`. Tenant overlay edges follow in #2360. Decisions: `docs/audit-log/1777-crosswalk-edge-remap-decisions.md`.
