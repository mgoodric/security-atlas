- **feat(connector/azure): slice 658 — opt-in Event-Grid provision / deprovision subcommand.** Resolves the slice-522 write-scope boundary: the long-lived `eventgrid` receiver receives events but deliberately does NOT auto-create the Azure Event-Grid system topic + event subscription (or the Activity-Log diagnostic setting) that route events to its webhook, because that needs a write scope the steady-state receiver must never hold. This slice adds a SEPARATE, opt-in, one-shot `atlas-azure provision` / `deprovision` (alias `provision --teardown`) the operator runs with their OWN ELEVATED, short-lived Azure credential — read from DEDICATED env vars (`AZURE_PROVISION_TENANT_ID` / `AZURE_PROVISION_CLIENT_ID` / `AZURE_PROVISION_CLIENT_SECRET`), resolved explicitly so a receiver credential in `AZURE_*` can never be silently borrowed. `provision` PUTs the system topic + the event subscription (pointed at `--webhook-host` + `--path`, carrying the delivery key as a secret static delivery-attribute) and — with `--with-diagnostic` — the subscription-level Activity-Log diagnostic setting; ARM PUT is upsert, so re-running is idempotent. `deprovision` DELETEs them (404-is-no-op, so teardown is idempotent too). The receiver gets NO write code path (P0-658-1, guarded by a test that fails if the receiver ever constructs the write client or acquires an elevated token); provisioning talks to Azure's ARM management API only and does NOT widen the platform push wire (invariant #3 / P0-658-2) — no new evidence kind. Consistent with the connector's six existing read kinds, the ARM write surface is a thin raw-HTTP client behind an injectable interface (no `azure-sdk-for-go` dependency added); the exact RBAC actions the elevated credential needs (`Microsoft.EventGrid/systemTopics{,/eventSubscriptions}/{write,delete}` + `Microsoft.Insights/diagnosticSettings/{write,delete}`) are documented in the README and printable via `provision --print-rbac` as operator-supplied, never connector-held. Unit-tested via the injectable seam + httptest (Azure is unreachable in CI). Provisioner: `connectors/azure/internal/provision`; subcommands: `connectors/azure/cmd/atlas-azure/cmd_provision.go`. Decisions log: `docs/audit-log/658-azure-provisioning-decisions.md`; slice doc: `docs/issues/658-azure-eventgrid-subscription-autoprovision.md`.
