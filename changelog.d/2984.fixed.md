- **fix(policy): policy sync drift no longer ignores whitespace changes inside code fences or a trailing two-space hard break (#2984).** The drift comparison added in #2910 normalised whitespace line by line, so a blank line or trailing space changed inside a fenced code block, or a Markdown hard break added or removed, was not reported as drift. Lines between fence markers are now compared verbatim, and a trailing run of two or more spaces that renders as a line break is kept. Stored bodies and every recorded hash are unchanged.
