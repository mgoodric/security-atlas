- **fix(evidence): only the acknowledgement handler can write `policy.acknowledgment.v1` (#2873).** Since #2817 an acknowledgement record bound to no control counts for SOC 2 cc1_5, cc5_3 and cc7_4, so any push credential could forge acknowledgements through the evidence push. The generic push now refuses the kind: HTTP `POST /v1/evidence:push` answers 403 `scope_violation`, gRPC `Push` answers `PermissionDenied`, and the audit log records `rejected_scope_violation`. `POST /v1/policies/{id}/acknowledge` is unchanged. A connector that pushed this kind must stop; no stock connector does. The decisions log is `docs/audit-log/2873-owned-ack-kind-decisions.md`.
