- **fix(activity): the default window includes today (#2464).** The Activity page's default `to` was today's 00:00 UTC, which the server reads as exclusive, so events from today never showed until the viewer widened the window. The default now ends at the exact instant the page opened (an RFC 3339 timestamp, the same moment in every timezone); `from` stays at 00:00 UTC seven days back. The default is computed once in `web/lib/activity-window.ts` and fixed for the life of the page, so the feed and the export bar carry the same window. The server already accepts a `to` slightly ahead of its clock; a unit test now pins that. The #2172 module-access e2e drops its explicit-window workaround, and `web/e2e/timezone-denver-2464.spec.ts` checks the default under America/Denver.
