- **feat(connectors/sharepoint): the SharePoint policy connector, on the policy-sync contract (#2837).** New binary `atlas-sharepoint run` reads every document in one SharePoint Online document library through Microsoft Graph, with an Entra app registration's client credentials kept on the connector's side. It takes each document's policy metadata from library columns (`Policy version`, `Approved by`, `Approval date`, `Effective date`, and the optional ones), converts each `.docx` to Markdown, and pushes the full set to `POST /v1/policies:sync` with a `policy-sync` API key, exactly as the Confluence connector does. Images, equations, embedded objects, footnotes and nested tables leave a visible marker and are listed per document; a file that is not a `.docx` is sent unreadable with its reason. A synced policy now names its source: the badge, the approval line and the 409 on an in-tool edit say SharePoint or Confluence, from the new `sync_source` field on `GET /v1/policies/{id}`. The sync endpoint's contract is unchanged. See `connectors/sharepoint/README.md`.
