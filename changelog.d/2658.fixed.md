- **fix(activity): a hand-picked "To" day includes that day, and the date inputs show the viewer's local date (#2658).** Picking a "To" day used to send that day's 00:00 UTC, which the server reads as exclusive, so choosing today showed nothing from today. The page now sends the start of the next day in the viewer's timezone, and a picked "From" day starts at local midnight. Both date inputs render the viewer's local date instead of slicing the UTC timestamp, so on a Denver evening the default "To" reads as today rather than tomorrow; the labels drop "(UTC day)" and "To" is marked inclusive. Until the page hydrates the inputs show the UTC day, so the server HTML still matches. The helpers live in `web/lib/activity-window.ts`; the shared `useHydrated` hook moves from `components/ui/timestamp.tsx` to `web/lib/use-hydrated.ts`. `web/e2e/timezone-denver-2658.spec.ts` picks today in "To" under America/Denver and expects an event written moments ago.
