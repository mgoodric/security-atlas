- **feat(web): one Export menu and useful bulk actions on `/controls` (#2141).** The six export buttons fold into one Export menu; every format keeps its URL. Selected controls can be assigned to anyone (people picker, all or none), evaluated now, linked to an action plan, or sent to the request-exception form, which files one exception per control. Evaluate and link report per control: how many succeeded and each refused control with the platform's reason. Each action shows only for callers the live `/v1/me` allows (assign owner, link and request exception need an approver; evaluate also admits a control owner), and link and request exception only when Risk and Exceptions are on for the caller. A viewer gets no selection column. The 200-control cap is mentioned only when a selection exceeds it.
