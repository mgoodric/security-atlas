- **feat(risks): import a risk register from the web, mapping its columns and values before anything is approved (#2848).** `/risks/imports` (an Import button on the Risks page) takes a CSV or XLSX register and a scoring methodology, then shows each detected header with the risk field it maps to (pre-filled from the platform's aliases, changeable), the unmapped columns and a preview of the first rows. A file whose headers match no alias is offered with its fullest early row as the header and maps by hand. Staging sends the mapping as the upload's column map; the batch's category and theme values are then mapped to existing ones or created (approvers only), and the batch opens on its review page. New API: `POST /v1/risks/imports/preview` reads an upload's header mapping and first rows without staging, and the upload accepts a repeatable `ignore_column=Header` to keep an alias-matched column unmapped. The mapping step is a shared component (`web/components/import/column-mapping.tsx`) over a field-agnostic helper (`web/lib/import/column-mapping.ts`), for the controls import to adopt (#2836).
