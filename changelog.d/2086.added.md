- **feat(web): pick frameworks, users and API keys by name instead of pasting UUIDs (#2086).** One searchable `<EntityPicker>` (`web/components/ui/entity-picker.tsx`, on new combobox primitives in `web/components/ui/combobox.tsx` built from base-ui's Combobox, no new dependency) replaces four UUID fields: the framework version on New audit period (listed as name and version, e.g. "ISO/IEC 27001:2022"), the owner on New action plan, the user on Admin › Super admins grant, and the actor filter on Activity (people, API keys by owner, and "You"). Every picker still accepts a pasted ID, checked on entry: a valid one is selected (and shown by name when listed), an invalid one shows an inline error. Users and API keys come from the `<Person>` directory (`GET /v1/people`); framework versions from `GET /v1/frameworks?include=versions`, a new additive parameter that lists each framework's global versions.
