- **feat(scfimport): an SCF release import carries tenant overlay edges forward too (#2554).** `atlas-cli catalog import-scf` now copies each tenant's active overlay edge whose SCF anchor keeps its code and title in the new release onto that anchor, inside that tenant's own context (as `atlas_app` under the tenant, so RLS binds it). The carry is recorded as an approved overlay remap decided by `system:scf-import` in the tenant's remap history and overlay audit trail, and the author column shows "System". The legacy overlay edge stays active, so `?scf_release=<old>` reads the same as before. Every other overlay edge stays an open proposal for the tenant's writers. A same-code proposal whose requirement already maps to that anchor, catalog or overlay, is now closed as `kept_legacy` with the reason, instead of left open where no approval could succeed. The import prints `overlay_edges carried_forward=<n> closed=<n>`, and `crosswalk_edges carried_forward=<n> closed=<n>`.
