- **fix(evidence): a routed record pushed with an explicit control UUID reaches only the controls that declare its kind (#2931).** Evaluation, evidence summaries, control detail, the checklist, the portfolio and freshness used to read such a record for the named control even when that control's queries don't declare the kind. Population, period and auditor readers did not. Every reader now applies the same rule. A record of a bound kind that names a control only by `control_ref` still reaches that control. `atlas-cli evidence push` no longer requires `--control` for a routed kind. When `--control` is given for one, the CLI prints a note that it is kept as provenance, where it used to warn about a mistyped bundle ID.
