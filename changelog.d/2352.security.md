- **fix(modules): the module gate refuses a path whose owning module it cannot resolve (#2352).** When two modules tie for a path, or the registry otherwise fails to place it, the request now answers 503 `module_state_unavailable`, the same as a failed switch read, instead of reaching the router unchecked. A path no module owns is not a registered route and still gets the router's 404. A route-to-module golden (`internal/api/testdata/routes_modules.golden`) puts every route's owning module in review, and migration `20261130000000`'s reset of stored-off module switches is tested against seeded tenants.
