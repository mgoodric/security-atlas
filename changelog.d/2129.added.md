- **feat(risks, vendors): risk and vendor owners are users (#2129).** Risks and vendors gain an owner user (`owner_user_id`), set with the user picker on their forms and on the risk page, and returned by the API with any `owner_unlinked` text. Migration `20261216000000` links each existing free-text owner to the one active user of the same tenant whose name or email it equals (ignoring case); ambiguous or unmatched text is kept and shown as "Owner (unlinked)" with a prompt to pick the user. An owner that is not an active user of the tenant is refused with 422, and every change is audited (`fields_changed` for risks, `vendor_owner_update` for vendors). `scripts/owner-link-dry-run.sql` reports the per-tenant counts before migrating. GLOSSARY.md defines Owner and Owner role.
