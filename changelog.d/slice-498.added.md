This slice extracts the three load-bearing, security-critical pieces into a dedicated foundation so the surfaces become thin consumers. **(1) `internal/llm` client** — a narrow, provider-agnostic `Client` interface (`Generate(ctx, GenerateRequest) → (GenerateResult, error)`; request = system prompt + pre-assembled context + optional model id + **mandatory** token budget + timeout; result = opaque text + resolved `model_name`/`model_version`/`model_provider`) with a **local Ollama** implementation as the default (Llama 3.1 8B per slice-182 D5, read from `ATLAS_LLM_*` config; never egresses past the configured local endpoint — P0-498-1, no cloud routing = slice 499) and a `StubClient` CI seam (the documented unblock so 440/441/444/471 stub identically without a live Ollama). The client takes **pre-assembled context** — no pgvector / retrieval (P0-498-2 = slice 500). Caps are enforced **before** any inference: an over-cap or timeout-less request is rejected, never an unbounded job (P0-498-6). Model output is opaque text in/out — never executed, eval'd, or interpolated into SQL/shell/path (P0-498-7). **(2) `ai_generations` audit record** (`migrations/sql/20260607000000_ai_generations.sql`) — one tenant-scoped, **append-only** row per generation across every surface (`surface` enum, `prompt_version`, model name/version/provider, full system prompt, assembled `context_inputs` JSONB, `raw_draft`, `surface_subject` linkage, `created_at`); written via **parameterized sqlc**; **four-policy-shaped RLS** on `app.current_tenant` (append-only → SELECT + INSERT policies only under `FORCE`, no UPDATE/DELETE policy + no UPDATE/DELETE grant = immutable snapshot, P0-498-5; same pattern as `evidence_audit_log`/`decisions_audit`/`artifact_access_log`). **(3) Reusable enforcement** — a shipped IMMUTABLE SQL function `ai_assist_human_approver_guard(ai_assisted, human_approved, human_approver)` adopted by a one-line CHECK on each approvable consumer record (so the boundary predicate is authored once going forward), mirrored by a Go guard (`llm.EnforceApproval`) for friendly early rejection;
