- **fix(web): Markdown soft line breaks render as spaces, not `<br/>` (#2455).** The shared renderer (`web/lib/markdown.ts`) joined every source line of a paragraph with `<br/>`, so help modules, policy bodies and other long-text fields broke wherever the `.md` file wrapped. A single newline inside a paragraph now renders as a space, per CommonMark; a hard break (two trailing spaces, or a trailing backslash) still renders as `<br/>`, and a hard break on a block's last line is dropped. The same rules apply inside block quotes and list items, and a list item now takes its continuation lines (indented or lazy) instead of spilling them into a paragraph after the list. Fenced code is untouched. The escape-first sanitiser is unchanged: `<br/>` is emitted by the renderer, never taken from input.
