- **fix(authz): attesting a control, and editing the CSF assessment, check the signed-in user's live roles, not the role list in their session token (#2523).** A user whose matching role was revoked could keep attesting until the token expired. Now the revoke takes effect on the next request, and granting the role back applies at once, with no re-login. API keys, machine (client_credentials) tokens and admins are unchanged. A user whose only role is control_owner can now submit an attestation for a control they own; the authorization policy used to refuse them before the ownership check ran.
