- **feat(admin): group-role mapping and API key changes are audited (#2609).** Each one writes a `me_audit_log` row in the same transaction as the change, naming the acting user and credential (`actor_principal`). If the audit write fails, the change rolls back. Creating or deleting a group-role mapping (`/v1/admin/group-role-mappings`) writes `group_role_mapping_create` or `group_role_mapping_delete` with the mapping id, source IdP config, group and role. Issuing, rotating or revoking an API key (`/v1/admin/credentials`) writes `api_key_issue`, `api_key_rotate` or `api_key_revoke` with the key id, last4, `is_admin` / `is_approver`, owner roles, allowed kinds, scope predicate and TTL. A rotation records the predecessor's retirement and the successor. The token and its hash are never recorded. Migration `20261263000000_group_mapping_api_key_audit` extends the action CHECK.
