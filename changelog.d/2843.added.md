- **feat(risks): a risk import matches each risk's owner by email (#2843).** `POST /v1/risks/imports` maps an owner column (`Owner`, `Risk Owner`, `owner_email`, the export's `treatment_owner`, or `--column-map owner=<Header>`). A value that is the email of an active user of the same tenant, ignoring case, becomes the risk's linked owner; anything else (a name, an unknown or disabled address, another tenant's user) is kept as the unlinked free-text owner and the row is flagged `owner_unlinked` on the review page. A user disabled between upload and approval is created with their display name as the unlinked owner. Migration `20261291000000_risk_import_owner`.
