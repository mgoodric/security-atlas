- **fix(scim): a failed last-admin alert no longer rolls back the SCIM deprovision; the notifier validates its user argument (#2504).** The super-admin notification and the `tenant_last_admin_deprovisioned` audit write each run under a SAVEPOINT. An error in either rolls back only that step and is logged at ERROR, and the deprovision commits, so a departed person loses access even when the alert fails; a notify failure is recorded on the audit row as `notify_error`. `notify_super_admins_last_admin_deprovisioned` now refuses a user that is not an existing, inactive user of the caller's tenant (migration `20261243000000`).
