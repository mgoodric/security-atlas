- **fix(crosswalk): a crosswalk's STRM content wins on an SCF-remap carried edge it lists by code (#3073).** Suppose a remap carried requirement R's edge from X onto Y, and a crosswalk later moved R from X to Y. The carried copy used to keep X's relationship, strength and rationale in default coverage. The import now rewrites the copy's content in place. It keeps the copy's row, tier history and remap link, re-seeds the tier per ADR 0018 §2, and records the replaced content in a transition. A copy a reviewer has moved through the tier workflow is left alone and reported. `import-crosswalk` and `converge-crosswalks` print each carried edge they update or keep.
