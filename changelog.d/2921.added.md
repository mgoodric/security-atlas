- **feat(connectors/osquery): read firewall and screen lock from named Fleet policies (#2921).** Fleet's host API has no firewall or screen-lock field. `atlas-osquery run --mode fleet` now takes `--firewall-policy "<name>"` and `--screenlock-policy "<name>"`, and reads each host's result for that policy from the Get host `policies[]` array: `pass` is true, `fail` is false, and an empty result or missing policy leaves the field out. Records move to `osquery.host_posture.v1` schema 1.2.0 (additive; 1.0.0 and 1.1.0 stay registered), which adds `firewall_source` / `screen_lock_source` (`fleet_policy:<name>`). The operator creates the policies. The connector README has example queries for macOS, Windows and Linux. With `--screenlock-policy` set, a Fleet host can `pass` again.
