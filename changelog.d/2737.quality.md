- **quality(web): an ESLint rule replaces the upstream-error regex sentinel (#2737).** `atlas-upstream/no-raw-upstream-error` flags any read of a response body's `error` outside `upstreamErrorMessage` / `upstreamErrorText`, including the uncast shapes the #2645 regex missed because `res.json()` is `Promise<any>`: `(await res.json()).error`, `const { error } = await res.json()`, and `j.error || …` / `j.error ?? …` on a variable bound to a parsed body. It keeps the regex's three syntactic shapes. `lib/api/upstream-error-sentinel.test.ts` is removed; its self-tests moved to `web/eslint-rules/no-raw-upstream-error.test.ts`. The `risks.test.ts` 5xx case now asserts the exact status line.
