- **fix(evidence): "All time" on the `/evidence` Since pill shows records older than 30 days (#2794).** The page sent no `since` for "All time", so `GET /v1/evidence` applied its 30-day default window. It now sends `since=1970-01-01T00:00:00Z`. "Last 30 days" is now the pill's default, the same window the page always loaded, so an ordinary page load does not read the whole ledger. Pick "All time" for the rest (`since_preset=all` in the URL). The per-control evidence tab is unchanged.
