- **feat(risks): the risk import finds the header row by its title and category columns, and a security-atlas risk export re-imports with no column map (#2840).** The header is the first of the first five rows that names both a title and a category column (by alias or column map), so a title or notes row above it is skipped even when it holds words like "Risk" or "Reference". A column map naming a header that is not in the file is reported as such rather than as a missing header row. A CSV or XLSX file from `GET /v1/risks/export` stages with no mapping; the export columns the import does not map yet (the risk uuid, severity, timestamps, ids) land in unmapped.
