- **fix(controls): one malformed `last_seen_at` no longer makes the osquery posture checks inconclusive for every host (#2939).** `soc2_cc6_6_boundary_protection`, `soc2_cc6_8_malware_protection`, `soc2_cc7_2_anomaly_detection` and `soc2_a1_1_capacity_monitoring` ordered each host's records by a `last_seen_at` cast that only a start-anchored prefix guarded, so a value like `2026-13-45T00:00:00Z` errored the whole query. They now use the full RFC 3339 guard plus `pg_input_is_valid` that cc4_1 uses. A malformed value, or one more than an hour after the evaluation instant, ranks as a missing one does, and the host's checked field still decides. `docs/spec/control-bundle.md` documents the guard ("Reading a payload timestamp"), and a test refuses an unguarded payload timestamp cast in the stock bundles. **Upgrade note:** the four queries changed, so on the next boot each bundle is superseded by a new version. Owners, evidence, exceptions and risk links stay with the old version and have to be moved by hand.
