- **fix(calendar): `/calendar` no longer crashes when an offboarding checklist is due (#2215).** `GET /v1/calendar` already returned open offboarding checklists as `offboarding` events, but the web calendar threw on the unknown type and replaced the page with an error. Offboarding events now render and link to `/personnel-security/{id}`, `?types=offboarding` is accepted, and the type filter lists "Offboarding due". Because the title carries the person's work email, offboarding events reach only callers OPA lets read personnel security (GRC engineer, admin); auditors, control owners and viewers do not see them, and the ICS feed never carries them. Any event type the web app does not recognise now renders as plain, unlinked text instead of taking down the page.
