- **fix(authz): an API key bound to a user counts a canonical role label only while its owner holds that role (#2541).** A key minted with a `control_owner`, `grc_engineer` or `admin` label no longer keeps that role after the owner's role is revoked: the attest, policy-ack and tenant admin/approver gates read the owner's live roles for such labels. Free-text labels (e.g. `security-engineering`) and unbound keys are unchanged. The CSF edit refusal now says that admin means a tenant admin or a super-admin, and the Exceptions help says that starting, ending or revoking an exception re-evaluates the control.
