- **fix(authz): policy import admits a live-role tenant admin (#2665).** `POST /v1/admin/policies/import` now gates on `authz.IsTenantAdmin`, so a user holding the live `admin` role in `user_roles` can import policies into that tenant without the credential admin flag, matching the OPA bundle and every other admin-only handler since #2428. This widens effective access to policy import to every tenant admin; a role claim on a token for a tenant where the user holds no live role is still refused.
