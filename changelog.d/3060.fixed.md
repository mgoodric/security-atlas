- **fix(evidence): a write refused by a concurrent audit-period freeze answers 409 `concurrent_freeze`, not 500 (#3060).** Closing an incident or completing a personnel-security item while an audit period freezes used to fail with an opaque internal error. It now answers `409` with code `concurrent_freeze`; nothing was written, and resubmitting it succeeds. A push that a freeze refuses on all three attempts answers the same 409, or gRPC `ABORTED`. `evidence_audit_log` records these refusals as `rejected_concurrent_freeze` instead of `rejected_internal_error` (migration `20261310000000`). The live-ingest freeze check now refuses to run in a transaction above READ COMMITTED, where it could miss a freeze.
