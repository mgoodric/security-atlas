- **fix(modules): background senders fail closed when a module switch cannot be read (#2548).** The decision-overdue and personnel overdue-offboarding notifiers, the email, Slack and webhook digests, and the board pack generator no longer fall back to a switch's seed default when the flag store's read fails. The notifiers skip that tenant for the sweep and retry on the next; the digest is not sent until a later sweep can read the switch; pack generation returns an error. Request paths are unchanged. Switching a module back on still notifies every still-overdue item once, by design (see `docs/audit-log/2548-background-senders-fail-closed-decisions.md`).
