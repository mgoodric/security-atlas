- **feat(policies): a synced policy whose Confluence page disappears is reported and flagged, and stays in force (#2853).** Each `POST /v1/policies:sync` run carries the full set of its source's labelled pages, so a page with a published synced policy that a run does not carry has lost its label or been deleted. The run report lists it with status `missing`, a `missing_since` time and a `missing` count. The policy itself is unchanged: it stays published, is not superseded, and staff can still acknowledge it. The policy API returns `sync_missing_since` on `GET /v1/policies/{id}` and `GET /v1/policies`, and `GET /v1/needs-attention` lists the policy in a new `source_missing` band, ranked after approvals and before overdue items and owned by the policy's owner role. Both clear when a later run carries the page again. A page the run carries but skips for a bad property counts as present. Only policies of the run's own source in the caller's tenant are considered. Migration `20261285000000_policy_sync_missing` adds the column, allowed only on synced rows.
