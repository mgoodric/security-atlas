- **feat(dashboard): posture targets per framework (#2136).** An admin or GRC engineer sets a framework version's posture target (target coverage, warning and critical thresholds, direction) from its dashboard tile with "Set target" / "Edit target". The tile then colours coverage by the shared threshold rule and names the band ("On target", "Warning", "Critical"); without a target it stays neutral with "No target set", and a version with no activated scope still says "Scope not set". Backed by `GET`/`PUT /v1/framework-scopes/posture-targets/{framework_version_id}` (every role reads; admin and grc_engineer set; the version must have an activated scope) and a `target` field on each `GET /v1/frameworks/posture` row. Each set is logged before and after in the same transaction and shows in the unified audit log as kind `posture_target` (migration `20261214000000`).
