- **fix(credentials): an API key acting as tenant admin mints no key wider than itself (#2656).** A key that is a tenant admin by its `admin` label, and is not an admin credential, can no longer mint, or rotate into existence, a key that expires after it does, has a wider `scope_predicate`, or may push kinds it may not; each is refused with 403. Scope containment is checked by the new `scope.PredicateWithin`, which is sound but conservative: a narrower scope it cannot prove is refused. Admin credentials and JWT sessions are unaffected, and revoke is not bounded.
