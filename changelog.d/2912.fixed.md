- **fix(connectors/osquery): unread posture fields are omitted instead of pushed as false, and records carry the host's last-seen time (#2912).** Fleet's documented Get host response has no firewall or screen-lock field, and reports MDM as `mdm.enrollment_status`, so the connector was pushing `firewall_enabled`, `screen_lock_enabled` and `mdm_enrolled` as `false` for every Fleet host, and failing every disk-encrypted host on "screen lock disabled". It now pushes `osquery.host_posture.v1` at schema 1.1.0 (additive; 1.0.0 stays registered). A boolean appears only when it was read; `mdm_enrolled` comes from `mdm.enrollment_status`; new `last_seen_at` carries Fleet's `seen_time`; and new `reason` says why a result is inconclusive. **Behaviour change:** a Fleet host is now `fail` (disk encryption off) or `inconclusive` (screen lock not reported), never `pass`. Existing ledger rows are unchanged.
