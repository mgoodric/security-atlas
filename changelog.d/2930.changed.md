- **feat(schemaregistry): a schema version can opt in to enforcing JSON Schema `format` (#2930).** A version that sets `"x-assert-format": true` now refuses values that don't match its `format` keywords (`date-time`, `uri`, `email`, `uuid`, `date`) at ingest. Without the key, `format` stays annotation-only as before, so no existing version's acceptance changes. A non-boolean value fails schema compilation. Decisions in `docs/audit-log/2930-schema-format-assertion-decisions.md`.
