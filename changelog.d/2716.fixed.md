- **fix(openapi): reflected response schemas follow encoding/json on field-name conflicts and `,string` marshalers (#2716).** `jsonFields` now ports encoding/json's dominance rules (shallower field wins, then the tagged one; a tie at one depth drops both, as does one struct embedded twice), so an outer field shadowing an embedded one can no longer emit a duplicate YAML key or a wrong `required` list. A type with its own marshaler tagged `,string` is refused (the marshaler wins on the wire), not documented as a string, and the marshaler error names the schema and field path (`Report.items[].at`). The committed `docs/openapi.yaml` is unchanged.
