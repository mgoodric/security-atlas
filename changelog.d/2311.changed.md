- **feat(risks): risk edits refuse a stale version, and the history read is capped (#2311).** `PATCH /v1/risks/{id}` takes an optional `If-Match` with the ETag `GET /v1/risks/{id}` returns (the quoted `updated_at`) and answers 412 when the risk changed since; the web edit form always sends it and offers to reload. A PATCH body over 1 MiB is a 413. `GET /v1/risks/{id}/audit-log` takes `?limit=` (default 200, at most 500) and says `truncated` when older rows exist; the History section says when it shows only the latest changes. The edit form warns that changing the methodology resets the residual score. API clients that send no `If-Match` keep last-write-wins.
