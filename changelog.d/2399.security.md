- **fix(web): one tenant's people names never render for another tenant after a re-login in the same tab (#2399).** The browser cache of the people directory `<Person>` resolves against is now keyed by the session's tenant, read from the session cookie on the server. With the tenant unknown, names stay on the loading state rather than reading a cached directory. The login page also clears every query the previous session cached, so a session expiry followed by a sign-in to another tenant starts with an empty cache.
