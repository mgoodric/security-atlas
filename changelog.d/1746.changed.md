- **fix(risk): new risks default to `untreated`, and an acceptance carries a status (#1746, #1829, follow-ups #1831).** Before #1746 the app layer silently set `treatment = 'avoid'` on any risk created or imported without an explicit treatment, so some `avoid` rows record a decision nobody made. **Upgrade note:** review them with `SELECT id, title, created_at FROM risks WHERE treatment = 'avoid' ORDER BY created_at;` and move each true no-decision to `untreated` through the MCP `update_risk_treatment` tool (a write proposal, confirmed with `confirm_write`). `PATCH /v1/risks/{id}` (#1749) moves level and org unit only and does not change treatment. **Output change:** board-pack and brief treatment strings for accepted risks now read `accept (approved)` or `accept (proposed)` instead of `accept`; update anything that parses that text. The `open_risk_financial_exposure` metric counts every risk outside an approved acceptance (`treatment <> 'accept' OR acceptance_status IS DISTINCT FROM 'approved'`), and the dashboard's top-risks badge shows the acceptance status.
