- **fix(policies): a draft written or edited through an unbound API key, OAuth client or bootstrap admin can no longer be approved unflagged (#2459).** Such a draft has an unknown author, because anyone holding that credential could be the approver. Every approver now gets 403 unless the organisation allows self-approval, and the approval is then flagged `self_approved`. Draft edits report a missing policy (404) or a non-draft policy (409) before a bad linked control (422), and create reports a bad predecessor first. A retired control no longer counts as a linked control.
