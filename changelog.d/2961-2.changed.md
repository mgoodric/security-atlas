- **feat(risks): `POST /v1/risks/aggregate` applies the hierarchy link rules (#2961).** The aggregate's children are linked the same way as `POST /v1/risks/{id}/children`, so each child's level must be below the parent's level (team < org < company), and a request may name at most 100 children. A request that breaks either rule now gets a 400 and creates no parent. Before this change, both were accepted.
