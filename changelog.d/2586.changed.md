- **fix(policies): the acknowledgment rate counts exactly the members who may acknowledge; the admin import holds audiences to the enum; machine credentials cannot acknowledge (#2586).** A policy's acknowledgment-rate denominator, on its own page and in the policy list, now counts active users holding a live role the audience names (any live role for Everyone). Before, it counted holders of unrevoked API keys: a user whose role was revoked but whose key was not stayed on the roster although they could no longer acknowledge, and a member who signs in without an API key was left off although they could. Rates can change on upgrade for that reason. `POST /v1/admin/policies/import` now fails a policy file whose `acknowledgment_required_roles` names anything other than the five roles or `everyone`, listing every unrecognised value; with `partial` the other files still import. `POST /v1/policies/{id}/acknowledge` from a credential not bound to a person (an unbound API key, the bootstrap key) is refused with 403.
