- **feat(admin): API keys issued, rotated or revoked over the gRPC `AdminCredentialsService` are audited (#2652).** The gRPC path now writes the same `api_key_issue`, `api_key_rotate` and `api_key_revoke` rows in `me_audit_log` as `/v1/admin/credentials` (#2609), in the same transaction as the change, naming the acting user and credential. If the audit write fails, the change rolls back in the database and in memory. Revoking a memory-only bootstrap key is recorded too. The token and its hash are never recorded. No migration.
