- **fix(connectors/manual): manual connector records pass the `manual.upload` schema, and re-runs keep the first `observed_at` (#2940).** Every path (local CSV, S3, SFTP) emitted fields `manual.upload` 1.0.0 rejects, so ingest refused them and cc6_5 / cc9_1 got no connector records. The connector now pushes at a new, additive 1.1.0 that declares those fields. The local CSV key is derived from the row's content in place of the run hour, so a re-run over an unchanged file no longer re-stamps `observed_at`. S3 and SFTP re-runs after the first hour no longer abort on `AlreadyExists`: the connector warns on each such item and reports it as already ingested. The SFTP key now includes the file size, so a same-second rewrite is not skipped. Upgrade note: the first local or SFTP run after upgrading pushes each row or file once under its new key.
