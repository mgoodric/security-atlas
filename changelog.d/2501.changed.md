- **fix(modules): a member with no live role lacks module access; incident create refuses hidden-module links (#2501).** An owner who holds no live role in the tenant (none granted, or deactivated) is now flagged `owner_lacks_access` on vendors, risks and action plans, and owner pickers (`GET /v1/people?module=<key>`) leave them out; super-admins stay exempt. `POST /v1/incidents` answers 403 when `risk_ids` or `vendor_ids` name a module the caller cannot use, before any id is looked up, so the answer is the same whether the record exists. `GET /v1/people?module=<key>` answers 403 to a caller who cannot work in that module, so only people who can see the module's records learn who else can.
