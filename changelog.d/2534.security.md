- **fix(oidc): sign-in requests to a tenant's IdP are SSRF-guarded (#2534).** OIDC discovery, JWKS fetches and the token exchange now use a hardened client that checks every dialled address (closing DNS rebinding after the save-time preflight), ignores environment proxies and never follows redirects. Previously they used `http.DefaultClient`. The deny list now lives in one package (`internal/netguard`) shared by the SSO preflight and the webhook and Slack channels, and it also denies 0.0.0.0/8, 198.18.0.0/15, 240.0.0.0/4 (incl. 255.255.255.255), and NAT64 / 6to4 addresses that wrap an internal IPv4. Upgrade note: an IdP on loopback or a private network now needs `ATLAS_OIDC_ALLOW_PRIVATE_ISSUERS=true`; the SSO preflight's private-address opt-in follows the same setting, and with it on, link-local / cloud metadata is still denied.
