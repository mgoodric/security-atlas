- **feat(help): lifecycle diagrams in the "How this works" panel, checked against the backend (#2148).** A help file draws a lifecycle as a Mermaid state diagram; `just help-diagrams` pre-renders it to a light and a dark SVG from the app's theme tokens, so no diagram library ships to the browser (a CI bundle check fails if one does). The panel shows the SVG for the current theme and lists the diagram's states and transitions as its text alternative. A vitest check fails when a diagram's states or transitions differ from the exported lifecycle in `docs/lifecycles/`, or when a committed SVG is stale. The Controls help gains the exception lifecycle diagram; the docs site publishes the same SVGs.
