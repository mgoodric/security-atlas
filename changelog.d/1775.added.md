- **feat(catalog): the SCF remap queue (#1775).** When `atlas-cli catalog import-scf` makes a new SCF release current, every non-pinned control still on an older release's anchor gets one remap proposal. The proposal names its successor anchors from the new release's legacy IDs and is classified `unchanged`, `renamed`, `split`, `reused_id` or `no_successor`. A release without legacy IDs queues every control as `no_successor`. A proposal moves nothing: its `status` is `rebound` when the #1971 boot-time re-bind already moved the control (same code, same title) and `open` otherwise. The import prints a `remap_proposals` count per class. `GET /v1/controls/remap-proposals?class=&status=` lists the caller tenant's proposals (RLS). New table `scf_remap_proposals` (migration `20261119000000`). Decisions: `docs/audit-log/1775-scf-remap-queue-decisions.md`.
