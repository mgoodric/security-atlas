- **feat(sso): every SSO config change is audited (#2609).** `PATCH /v1/admin/sso` now writes a `tenant_sso_config_update` row to `me_audit_log` in the same transaction as the change: the acting user and credential (`actor_principal`), and the before and after value of every field, including `trust_unverified_email_for_link`. The client secret is recorded only as `secret_changed: true/false`, never its value, ciphertext, hash or length. If the audit write fails, the change rolls back. A PATCH that changes nothing writes no row. Migration `20261260000000_sso_config_audit` extends the action CHECK.
