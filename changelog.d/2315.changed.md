- **feat(scfimport): an SCF release import carries crosswalk edges forward (#2315).** `atlas-cli catalog import-scf` now copies every catalog crosswalk edge whose SCF anchor keeps its code and title in the new release onto that release's anchor, recorded as an approved edge remap decided by `system:scf-import`. Default requirement coverage, which reads the current release, no longer drops a crosswalk that declares the previous `scf_release`. Edges on a retitled, split, reused or withdrawn anchor stay on the old release with an open remap proposal for a super-admin, and the original edges are never changed, so `?scf_release=<old>` reads the same as before. The import prints `crosswalk_edges carried_forward=<n>`.
