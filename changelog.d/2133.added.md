- **feat(risks): saved views for the risk register (#2133).** The register gets the controls list's saved-views bar: save the current filters, sort, roll-ups toggle and chosen columns as a named view, apply it later, or delete it. Views are per user and stored under a new `risks` surface of `/v1/saved-views` (`?surface=risks` on GET, `"surface": "risks"` in the POST body; a request naming no surface is still `controls`). A risks view holds only `GET /v1/risks` filter and sort parameters plus chooser columns; an unknown key or value is a 400 on save, and an entry that later stops validating is dropped on read. Migration `20261248000000` widens the `saved_views.surface` CHECK.
