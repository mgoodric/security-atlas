- **feat(controls): stock control cc6_6 checks the host firewall, in SQL over the osquery host-posture payload (part of #2822, #1860).** `soc2_cc6_6_boundary_protection` now takes each host's latest in-window `osquery.host_posture.v1` record and passes when every one has `firewall_enabled` true. One host with the firewall off, or with the field missing, fails the control, and no in-window record leaves it inconclusive. It ignores the connector's per-record verdict, which is disk encryption plus screen lock, so a tenant that passed before can fail now, and the reverse. **Known gap:** a host whose posture the connector couldn't read is pushed with `firewall_enabled` false, so it fails this control until #2912 lands. The bundle now ships `tests/` cases, which the upload gate runs. The control's title is now "Endpoints reporting posture have the host firewall enabled". **Upgrade note:** the query changed, so on the next boot the bundle is superseded by a new version. Owners, evidence, exceptions and risk links stay with the old version and have to be moved by hand.
