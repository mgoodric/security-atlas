- **fix(controls): the `/controls` Freshness filter no longer offers "Expired", a state no control can have (#2359).** The options are now Fresh, Stale and No evidence, held by a test to the `freshness_status` CHECK on `control_evaluations`. An old link with `?freshness=expired` shows all controls instead of none. `GET /v1/controls?include=state&freshness=expired` now returns 400, like any other unknown freshness value.
