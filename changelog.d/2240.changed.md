- **fix(overlays): catalog deletes respect tenant overlay edges, and overlay rows drop the synthetic mapping tier (#2240).** Deleting an SCF anchor, a framework requirement or a framework version is refused while a tenant has an active overlay edge on it; a retired overlay edge still cascades, and its removal is recorded as `cascade_removed` in that tenant's overlay audit trail. An overlay edge can only name a requirement from a catalog framework version or its own tenant's, enforced in the database on insert and update. Overlay rows on `/v1/requirements/{id}/coverage`, `/v1/controls/{id}/coverage` and `/v1/anchors/{id}/requirements` no longer report `mapping_tier`. Creating an overlay edge on a pair whose catalog edge is `no_relationship` is now allowed, matching how coverage already counted it.
