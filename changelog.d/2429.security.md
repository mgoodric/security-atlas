- **fix(help): the lifecycle diagram SVG check and browser strip parse the file and allow-list its elements (#2429).** `public/help/diagrams/*.svg` can be opened directly on the app origin, so the Node gate (`unsafeSvgParts`) now parses each file as strict XML instead of matching regexes, and both it and the browser strip (`stripActiveSvg`) keep only an allow-list of static SVG elements. Every committed diagram still passes; no re-render was needed.
