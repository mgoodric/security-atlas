- **feat(web): SCF remap review page (#1778).** `/controls/remap` lists the remap proposals a reviewer can still decide, one tab per class with a count. Each proposal shows the legacy anchor (code, title, description) beside the proposed anchor or anchors and the affected control. Split, no-successor and reused-ID proposals need an explicit anchor, picked from the successors or from a search of the new release's catalog. A reused ID is flagged and shows what the code meant before and what it means now; it is never approved by default. Unchanged proposals can be approved with one call to the bulk endpoint. Crosswalk-edge proposals appear only for super-admins: the platform answers that read for them alone, and the page hides the section on a 403.
