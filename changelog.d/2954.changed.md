- **feat(confluence): `atlas-confluence run` exits 3 when an accepted push still needs attention (#2954).** A run exits 3 if more pages are `skipped by connector` than `--max-skipped` allows (default 0), or if the platform returns a `warnings` entry. Each warning is printed as a `warning:` line. Before this, a converter regression that refused many pages, but not all of them, exited 0 while the platform marked those policies `missing`. A 422 refusal of an empty push now prints the platform's message. Exit 1 still means nothing was pushed or the push was refused. **Upgrade note:** a scheduler that alerts on non-zero now alerts on these runs too. That is intended. Raise `--max-skipped` only for a page you have accepted cannot be converted. The live smoke run against a real Confluence site has not been done yet; see `docs/audit-log/2954-confluence-skip-exit-decisions.md`.
