- **feat(mapping-overlays): the audited-under report lists unresolved references, caps its size, folds duplicates, and has a CLI (#2324).** `GET /v1/mapping-overlays/audited-under` now returns `unresolved_references` and `unresolved_count`: tested-under references that name no requirement in the framework's current version, which the report used to drop without a word. The `/catalog/audited-under` page shows them as a data-quality note. Rows and unresolved references are each capped at `?limit=` (default and maximum 5000), with `total` and `truncated` saying what was cut; the CSV export takes the same cap, is streamed onto the response, and carries `X-Atlas-Truncated` and `X-Atlas-Unresolved-References` headers. Two references to the same criterion on one control are now one row, their distinct notes joined with "; ". New `atlas-cli mappings overlay audited-under` prints the report as a table, `--json` or `--csv`.
