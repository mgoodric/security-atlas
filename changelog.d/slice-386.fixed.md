- **fix(metrics): slice 386 — metrics_catalog seed aborted on empty source_slices.** `internal/catalog/metrics/seed.go` built the upsert param with `append([]string(nil), m.SourceSlices...)`, which returns a nil slice for empty input; pgx encodes nil `[]string` as SQL `NULL`, violating the `metrics_catalog.source_slices` NOT NULL constraint (the column DEFAULT applies only when the column is omitted, not when NULL is passed). Three catalog metrics declare `source_slices: []` (`backup_restore_validation`, `incident_response_drill_outcome`, `tabletop_exercise_outcome`), so the first aborted the single-transaction seed and left `metrics_catalog` empty — cascading into `metric_observations` FK violations in the scheduler sweep. Added a `nonNilStrings` helper (nil/empty → non-nil empty, populated → independent copy) with a unit regression test. Surfaced while diagnosing slice 385 on atlas-edge. The startup seed failure is logged-not-fatal and the metrics integration test skips without a migrator DSN, which is why CI stayed green.
