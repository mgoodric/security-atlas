- **fix(web): approving or rejecting an exception, drafting all questionnaire answers, or approving a checklist section while you switch tenants no longer leaves the old tenant's result in the new tenant's view (#2768).** These handlers wait on a plain request rather than a mutation, so the #2715 guard did not reach them. They now check whether the tenant changed while the request was in flight, and if it did, they skip the cache write and the navigation to the result. A new test fails the build if a future handler writes the cache after an awaited request without that check.
