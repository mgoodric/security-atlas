- **feat(confluence): convert Confluence storage format to Markdown for policy sync (#2855).** New pure-function package `connectors/confluence/internal/storagemd` turns a page body (XHTML with `ac:`/`ri:` elements) into Markdown, the platform's only policy body format. It converts headings, paragraphs, emphasis, links, nested ordered and unordered lists, task lists, tables, code blocks and block quotes. Info, note, warning, tip and panel macros become block quotes, and code and noformat macros become fenced code blocks. Any other macro, and any Confluence element with no Markdown form (an attachment image, for example), stays visible in the output as a marker and is listed in the result with a per-name count, so the connector can report it against the page. The output is byte-for-byte deterministic, which keeps the platform's body hash stable across runs. The end-to-end connector that uses it is #2856.
