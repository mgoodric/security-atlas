- **feat(framework-scopes): create a framework scope in the app with a wizard (#2115).** `/framework-scopes/new` (from the index's **New scope**, or the empty scope page's **Create a scope**, which replaces the "not available yet" line) picks the framework version, scopes **Everything** or values per dimension, keeps the JSON predicate editor under **Advanced**, and submits the named draft for approval through the existing create and submit routes. On a version's scope page the lifecycle action is now in the shared header: **Submit for approval**, **Approve**, **Activate**, or **New revision** once only frozen revisions remain (a new draft, never a change to the activated one). Approval stays the platform's rule, and its refusal (the submitter, or a machine credential) is shown as the platform words it. A null predicate (choose by dimension with nothing picked, or `null` typed under Advanced) is never submitted or saved.
