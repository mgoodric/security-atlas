- **fix(bootstrap): an install on its own SCF release boots again (#3061).** With `SCF_CATALOG` set to your own release, the docker bootstrap failed at the SOC 2 crosswalk, because the stock controls, crosswalks and policies declare the bundled sample's release (`test-2026.3`, #1773 / #3033) and that release was never loaded. The bootstrap now also loads the sample as a legacy release with the new `atlas-cli catalog import-scf --keep-current`, so your release stays current. It uploads the stock content, then re-imports your catalog so the stock controls and SOC 2 edges move onto your release wherever the SCF code and title match. A crosswalk that binds in an older release no longer retires the edge it wrote on the current release's anchor with the same code. The `import-scf` output line gains a `status=` field.
