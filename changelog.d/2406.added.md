- **feat(dashboard): carry a posture target forward to a new framework version (#2406).** Activating a framework scope on a new framework version now copies the tenant's posture target from the version the version-migration queue leads in from, the same rule the applicability carry-over (#1793) uses, so the tile is not neutral after an upgrade. It copies only when the new version has no target, so a target someone set is never overwritten and a second activation writes nothing. Each copy is logged as `carry_over` in the posture-target audit trail with actor `system:posture-target-carry-over`, the source version and the person who activated (migration `20261259000000`). For a version activated before this, each `GET /v1/frameworks/posture` row carries `prior_target`, and the Set target dialog prefills from it.
