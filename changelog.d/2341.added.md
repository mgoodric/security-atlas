- **feat(metrics): set a metric's target from its detail page (#2341).** An admin sets or edits a metric's target, warning and critical thresholds, direction and notes with "Set target" / "Edit target" on `/dashboards/metrics/{id}`, over the existing `PUT /v1/metrics/{id}/target` (still admin-only). The dialog refuses thresholds out of order for the chosen direction and previews each value in the metric's unit; percent metrics take fractions (0.9 is 90%). The board card's "No target set" links to the form only for a caller who may set a target, and is plain text for everyone else.
