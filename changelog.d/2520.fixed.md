- **fix(attest): a repeated attestation is recorded when a newer one has overtaken it (#2520).** Without an `idempotency_key`, `POST /v1/controls/{id}/attestations` posted fail, pass, fail inside five minutes used to return the first fail as a duplicate and leave the control passing. The repeat is now recorded and evaluated, so the control ends failing, while a plain retry still returns the first receipt. A client-supplied `idempotency_key` keeps strict dedupe; API callers should send one per attestation.
