- **feat(policies): an empty policy sync push no longer marks every synced policy missing by accident (#2902).** `POST /v1/policies:sync` with an empty `pages` list for a source that has published synced policies is refused with 422 and changes nothing, unless the request sets `allow_empty: true` to confirm the space is now empty. An empty push for a source with nothing synced is accepted as before. A run that leaves more than half of a source's published synced policies missing returns a `warnings` entry in the report. A pusher that sends empty sets on purpose must add `allow_empty: true`.
