- **fix(exceptions): cap scope-predicate size, cap the create body, store the whole control as `{"op":"true"}` (#2600).** The scope-predicate parser behind exception create and credential scope predicates now refuses an expression nested deeper than 32 levels or holding more than 1,000 nodes. `POST /v1/exceptions` caps its body at 1 MiB and returns 413 past it. A create that omits `scope_cell_predicate` or sends `{}` now stores the explicit `{"op":"true"}` instead of `{}`. It means the same thing, so no control state changes. The exception detail page shows such an exception as "Whole control". Existing `{}` and null rows are not rewritten in this change.
