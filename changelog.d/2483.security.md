- **fix(authz): a non-canonical uuid-shaped principal gets no stored roles (#2483).** `DBRolesResolver.RolesFor` now returns no roles for a key that parses as a uuid but is not its canonical lowercase form (upper-case, braced, `urn:uuid:`, 32-hex, the nil uuid), bare or as a `user:` subject. Such a key named no user, so the deactivation guard was skipped while the text match on `user_roles.user_id` could still hand back a row stored in that spelling. No path writes such rows today; this makes the lookup fail closed rather than rely on that.
