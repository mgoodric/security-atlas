- **feat(auth): a `policy-sync` API-key purpose, refused everywhere else (#2849).** `POST /v1/admin/credentials` accepts `"purpose": "policy-sync"` for a key that may only sync policies, the Confluence policy connector's key (#2813). Such a key carries no other grant. Its purpose appears in the key list, the web API-keys table and the `api_key_issue` audit row, and a rotation keeps it. Every existing route refuses it: 403 over HTTP, even with a session cookie, and PermissionDenied over gRPC, including evidence push and the admin services. The calendar feed and `atlas-cli oauth migrate-api-key` refuse it too. Rotating any purpose key through the HTTP route used to drop its purpose; it no longer does. The sync endpoint that accepts these keys is #2850.
