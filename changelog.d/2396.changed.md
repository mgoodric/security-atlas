- **fix(crosswalk): PCI DSS 1.4.1 is anchored on SCF `NET-06` Network Segmentation (macrosegmentation), not `NET-24` Wireless Networking (#2396, follow-up to #1978).** The rationale for 1.4.1, which covers controls between trusted and untrusted networks, already named Network Segmentation. The pinned SCF 2026.3 workbook maps 1.4.1 to `NET-06` and not to `NET-24`. The `NET-24` anchor was carried over from the old `NET-08` Wireless Network Security code. **Upgrade note:** on the next catalog import, the `1.4.1 → NET-24` crosswalk edge is retired and `1.4.1 → NET-06` is added. Coverage for PCI 1.4.1 now comes from controls anchored on `NET-06`. The PCI 5.3.1 rationale now uses `END-03`'s current title, "Endpoint Protection Mechanisms", and its anchor is unchanged.
