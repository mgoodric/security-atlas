- **feat(connectors): slice 442 — GCP connector (closes 442).** The highest-demand missing cloud after AWS, for the SaaS-startup persona that runs on GCP. ONE connector, TWO read-only evidence surfaces following the LOCKED slice-004 / slice-443 connector pattern (register-per-run, stable `actor_id`, hour-truncated `observed_at`, `cloud_project` scope minimum, vendor-native auth): **`gcp.iam_policy_binding.v1`** — one record per project-IAM `(role, member)` binding enriched with service-account inventory facts (Resource Manager `getIamPolicy` + IAM `serviceAccounts.list`; anchors **IAC-21** Privileged Account Management + **IAC-15** Account Review — the spec's IAC-22 candidate is absent from the bundled SCF fixture, so IAC-21 is the closest present anchor, decisions-log D3); and **`gcp.storage_bucket_config.v1`** — one record per Cloud Storage bucket (encryption / public-access-prevention / uniform-access / versioning / retention via `buckets.list` `projection=noAcl`; anchors **CRY-04** + **NET-04**, the same pair the analogous `azure.storage_account_config.v1` uses). Auth is **Application Default Credentials** / service-account key with the read-only `cloud-platform.read-only` scope; documented minimal roles `roles/iam.securityReviewer` + `roles/storage.bucketViewer` — **`roles/storage.objectViewer` (data-plane object read) is banned** (threat-model E / P0-442-2). **Over-collection is structurally impossible** (threat-model I): the connector emits IAM-binding + bucket-CONFIGURATION metadata ONLY — never stored object contents, a service-account KEY, or a secret VALUE; the credential is source-side (invariant #3), header-only, redacted in every `fmt` verb, and two build-failing guards (a reflection guard over the evidence structs + a pushed-payload guard) enforce it. `profiles_supported=[pull]` on an honest interval (recommended daily; not event-driven, not continuous); the platform wire stays **push** (invariant #3). The `gcpapi` adapter is the ONLY network-touching package (net/http over the GCP REST APIs — one new transitive indirect dep, zero new module vulnerabilities). New `connector-build-gcp` justfile target. **Type: JUDGMENT** — the two-kind shape, the IAM `(role, member)` grain + descriptive-verdict semantics, the SCF-anchor choices (each verified present in the bundled catalog), the `cloud_project` scope minimum, and the stable-field calls recorded in `docs/audit-log/442-gcp-connector-decisions.md`.
