- **feat(policies): an acknowledgment pins the version you were shown, and the policy page still says "You acknowledged version N" after a reload (#2668).** `POST /v1/policies/{id}/acknowledge` takes an optional `{"policy_version_id"}` and answers 409 when it is not the version the id names; the web app sends the version from the pending list. `GET /v1/me/acknowledgments?include=current` adds a `current` list of the caller's fresh acknowledgments, which the policy page reads. When the ack is recorded but its evidence record is not, the toast says so instead of reporting a plain success.
