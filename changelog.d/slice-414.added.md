- **feat(oscal): slice 414 — cosign-keyless OSCAL signing, opt-in private Sigstore (closes 414).** Phase 2 of the [ADR-0010](docs/adr/0010-oscal-cosign-signing.md) signing plan, per [ADR-0016](docs/adr/0016-oidc-identity-for-keyless-signing.md): adds the **`cosign-keyless`** OSCAL-export-bundle signing mode — Fulcio-issued short-lived cert + Rekor transparency-log entry — as an **OPT-IN** mode for the **private-Sigstore deployment shape**, using atlas's scoped `client:oscal-signer` OIDC identity (slice 188) federated into an **operator-run PRIVATE Sigstore** (Fulcio + Rekor, operator-controlled trust root). **Defaults are unchanged** — the air-gap `docker-compose` default stays `embedded-ed25519` (P0-414-2) and the connected/SaaS GA default stays `cosign-kms` (P0-414-3); keyless is never inferred and never targets public Fulcio for the runtime surface (options a/d rejected). The mode resolves only when explicitly selected (`ATLAS_OSCAL_SIGNING_MODE=cosign-keyless`) AND both `ATLAS_COSIGN_FULCIO_URL` + `ATLAS_COSIGN_REKOR_URL` are set. The signer obtains atlas's OIDC token → exchanges it at the operator's Fulcio for a signing cert → signs the deterministic bundle digest → uploads to the operator's Rekor → records the cert + identity + issuer (parsed from the issued cert) + Rekor log index + private endpoints in a new `keyless` manifest sub-object (`omitempty` — non-keyless/pre-414 manifests are byte-identical to before). Keyless verification dispatches via cert-identity + transparency-log inclusion against the operator's trust root, failing closed for a verifier that cannot check the keyless surface. **Implementation reuses the Phase-1 cosign-as-binary wrapper** (`internal/oscal/cosign`) — zero new `go.mod` dependencies (no sigstore-go). **Test strategy:** Fulcio cert issuance + Rekor upload are faked at the cosign-client boundary (a fake runner that writes a real test-CA cert + emits a Rekor index; a fake `IdentityTokenSource`), so the sign→verify→manifest→on-disk round-trip is exercised in unit + integration tests WITHOUT a live Sigstore. Coverage floors held (`internal/oscal` ≥69, `internal/oscal/cosign` ≥88). **Type: JUDGMENT** — library choice, OIDC-identity plumbing, manifest shape, and opt-in config surface recorded in `docs/audit-log/414-cosign-keyless-signing-decisions.md`.
