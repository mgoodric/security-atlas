- **fix(eval): Rego evidence queries receive each record's real `observed_at` (#2819).** The Rego sandbox input was documented as `{records: [{result, observed_at, …}]}`, but only `result` was set, so a policy saw the zero time. Each record now carries its `observed_at` as an RFC 3339 timestamp, per ADR 0028 decision 3, so a roll-up can weigh recency. No payload field reaches Rego, and the package doc no longer claims `hash`. A tenant Rego policy that relied on the zero time changes behaviour; no stock policy reads `observed_at`.
