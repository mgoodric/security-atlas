- **fix(backup): the local backup directory defaults to `$ATLAS_DATA_DIR/backups` (#1725).** It was hardcoded to `/var/lib/atlas/backups`, so a non-root run with `ATLAS_DATA_DIR` pointed elsewhere logged `mkdir /var/lib/atlas: permission denied`. An explicit `ATLAS_BACKUP_DIR` still wins, and with neither variable set the default is still `/var/lib/atlas/backups`. The docker-compose bundles set `ATLAS_DATA_DIR=/var/lib/atlas`, so their backup path is unchanged and still lands inside the `atlas-data` volume. **Upgrade note:** an install that set `ATLAS_DATA_DIR` to something other than `/var/lib/atlas`, left `ATLAS_BACKUP_DIR` unset, and was writing backups to `/var/lib/atlas/backups` now writes them to `$ATLAS_DATA_DIR/backups`. Retention and restore-verification look only at the new directory. To keep the old location, set `ATLAS_BACKUP_DIR=/var/lib/atlas/backups`, or move the existing backups into the new directory.
