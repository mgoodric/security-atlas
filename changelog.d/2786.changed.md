- **fix(pdf): PDF export on a deployment with no Chrome installed answers `409 feature_not_enabled` instead of `503` (#2786).** The board brief, board pack, questionnaire, walkthrough and policy PDF endpoints return `409 {"error": "PDF export is not enabled on this deployment: chrome is not installed", "code": "feature_not_enabled"}` when Chrome is missing, because retrying will not install it. A render that times out or finds the render queue full is still `503`, and now carries `Retry-After: 15`. **Upgrade note:** a client or monitor that treated the chrome-absent `503` as retryable, or matched on it, should branch on `code: "feature_not_enabled"` instead. Decisions: `docs/audit-log/2786-pdf-chrome-absent-409-decisions.md`.
