- **feat(oscal): slice 589 — vendor-claim read API + operator accept/reject/needs-info disposition.** Slice 512 lands a vendor's OSCAL component-definition as vendor-attributed CLAIMS (`imported_component_claims`, `is_vendor_claim=TRUE`, `claim_status='asserted'`) but ships no read surface and no operator action. This slice closes that gap. **Read API:** `GET /v1/oscal/component-definitions` (a tenant's imported component-definitions, most-recent-first) + `GET /v1/oscal/component-definitions/{id}` (one import's components + their vendor claims, flattened with the SCF-anchor mapping + an `unmapped` flag for the slice-512 `scf_anchor_id IS NULL` claims) — mirroring the slice-599 `oscalprovenance` read pattern: a pure SELECT over persisted Postgres rows, tenant-scoped via RLS + a defense-in-depth `tenant_id` predicate + a handler-level read gate (admin | grc_engineer | control_owner), and **never touching the compliance-trestle bridge** (the integration suite runs bridge-free). The `{id}` read is kind-pinned to `'component_definition'` so a profile/catalog id 404s. **Disposition write:** `POST /v1/oscal/component-claims/{id}:accept` / `:reject` / `:needs-info` (the colon-verb shape mirrors the slice-025 walkthroughs `/{id}:finalize` precedent) — gated tighter on `grc_engineer` (IsApprover) | IsAdmin (the slice-021 exceptions precedent: adjudicating a vendor's assertion is a write, not a view). **THE LOAD-BEARING BOUNDARY (canvas invariant #2 / P0-512-1):** a vendor claim is an ASSERTION, not platform-verified evidence — the disposition writes ONLY the claim's `claim_status` + `dispositioned_by`/`dispositioned_at`/`disposition_note` metadata and an append-only `imported_component_claim_dispositions` audit row; it NEVER writes to `control_evaluations` or the evidence ledger, and the slice-512 `is_vendor_claim = TRUE` CHECK is left untouched (the integration test asserts `control_evaluations` stays empty and `is_vendor_claim` stays true after an accept). Accepting a claim records that the operator CREDITS the vendor's assertion; it does not satisfy a control.
