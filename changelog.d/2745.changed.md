- **fix(connectors): the k8s NetworkPolicy verdict requires default-deny in both directions, and `--netpol-control` defaults to the stock segmentation control (#2745, follow-up to #2648).** A namespace now passes only when all-pods policies deny both ingress and egress by default. A namespace with default-deny in one direction only, which used to pass, now fails with a reason naming the open direction. The `atlas-k8s run --netpol-control` default changes from `scf:NET-06` to `network_segmentation_default_deny`, so NetworkPolicy records link to the stock NET-06 control on default flags instead of staying a free-form reference. **Upgrade note:** expect namespaces that are default-deny in one direction only to start failing `network_segmentation_default_deny`. An explicit `--netpol-control scf:NET-06` still stores a free-form reference; drop it to link the stock control.
