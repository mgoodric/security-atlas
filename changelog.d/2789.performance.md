- **perf(activity): the actor picker's module filter matches route keys, not raw paths (#2789).** `GET /v1/activity/actors` used to match every distinct decision path in the window against every registry route pattern. Paths carry IDs, so that cost grew with traffic. Each path is now collapsed to a route key first: a segment that matches no registry literal becomes `*`. Only the distinct keys are matched. On 100k decisions over 90 days the query went from 3.7 s to 243 ms (reads included), and from 1.5 s to 113 ms (reads excluded, the default). The list of actors returned is unchanged. Numbers are in `docs/audit-log/2789-activity-actors-route-key-decisions.md`.
