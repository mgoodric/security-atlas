- **`atlas-cli catalog import-crosswalk` warns on stderr when a frozen framework version keeps its stored text (#2008).** The `requirement kept <code>: … frozen` lines now go to stderr prefixed `warning:`, so scripted imports and the bootstrap log surface them. The new `--strict` flag makes the command exit non-zero when `differed` is above zero; the import has still committed. `data/crosswalks/README.md` states the authoring rules for the bundled crosswalks, which ship inside the binary: a copyrighted standard (ISO, PCI DSS, AICPA SOC 2) is never quoted, and a public-domain source (NIST, U.S. regulation) may be.
