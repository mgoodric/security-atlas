- **fix(policies): only a policy's audience can acknowledge it (#2728).** `POST /v1/policies/{id}/acknowledge` now returns 403 unless the caller is on the version's roster: an active user holding a live tenant role the audience names, or any live role for Everyone. That is the set the acknowledgment rate counts. The super-admin flag and api_keys labels no longer admit a caller, so acks that would be recorded but never counted are refused. `GET /v1/me/acknowledgments` uses the same rule. The policy row is now read `FOR SHARE` while an ack is recorded, so a concurrent publish waits for an in-flight ack.
