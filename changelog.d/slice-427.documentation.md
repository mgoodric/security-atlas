- **docs: slice 427 — auditor-facing "verify a signed OSCAL export" page in the docs site.** Publishes `docs-site/docs/audit/verify-export.md` so an external auditor handed a signed OSCAL export bundle can confirm it is authentic and untampered with stock tooling — no atlas internals. The auditor-verification flow already existed but only in the operator runbook (`docs/runbooks/oscal-signing.md`), which is not in the docs-site nav and so never reached the published site; this surfaces the auditor-facing subset. The page (auditor voice, second person, offline + read-only) covers: (1) reading `manifest.json` `signature.mode` to pick the path; (2) the `cosign-kms` path with stock `cosign verify-blob` against an operator-published public-key file, including a stock-tool recipe (`jq` + `LC_ALL=C sort` + `sha256sum` + `xxd`) to recompute the deterministic bundle digest (sha256 over sorted `filename:memberhash` lines) and the raw-32-byte-digest blob cosign reads on stdin; (3) the `atlas oscal verify <bundle-dir>` convenience path for either mode; (4) what verification proves vs. does not (tamper-detection + key-holder authenticity, but no transparency-log timestamp — the keyless/Fulcio/Rekor mode is slice 414, not shipped, and an admonition says so); (5) key-trust guidance — trust an out-of-band public key, never one embedded in the bundle. Adds a **For auditors** nav section in `docs-site/mkdocs.yml` (label chosen to disambiguate from the existing "Audit logs" entry), cross-links from the OSCAL SSP-export walkthrough at the hand-to-auditor handoff, and links back to the operator runbook + ADR-0010 for the configuration side without duplicating it. **All documented commands were hand-run against real signed bundles** (AC-11): a `cosign-kms` and an `embedded-ed25519` bundle were produced via a throwaway harness driving the production signers, the page's digest-recompute matched the manifest, `cosign verify-blob` returned `Verified OK`, a tampered member made both the digest diverge and cosign reject the signature, and `atlas oscal verify` returned `OK … (mode=embedded-ed25519)`; the harness was removed before commit (docs-only — no change under `internal/oscal/`, `cmd/atlas-cli/`, or the manifest format). `mkdocs build --strict` passes with the page wired into nav and all internal links resolving. **Type: JUDGMENT** — decisions log `docs/audit-log/427-auditor-verify-export-docs-decisions.md`.
