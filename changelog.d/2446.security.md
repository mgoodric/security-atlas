- **fix(policies): whoever wrote or edited a draft cannot approve it (#2446).** Policies now record their draft editors: the creator, plus every caller of `PATCH /v1/policies/{id}`. The approval rule counts each editor as an author. Before this, an admin could write a policy, have someone else submit it, and approve it unflagged. Now that approval answers 403 unless Allow self-approval is on, and then it is flagged `self_approved`. Each draft edit appends a `draft_edited` row to `policy_audit_log` with the body's sha256, never the body itself. Submit rows also record the hash and the editor set. `linked_control_ids` must name controls in the caller's tenant on create and edit (422 otherwise), and create and edit bodies are capped at 1 MiB (413). Migration `20261222000000_policy_draft_editors` adds `policies.draft_editors` and `policy_audit_log.body_sha256` / `editors`. Drafts created before the migration have no recorded editors and keep the submitter-only check.
