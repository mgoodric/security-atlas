- **feat(controls): stock network segmentation control on SCF `NET-06` (#2648, follow-up to #2396).** ISO A.8.22 and PCI 1.4.1 are covered by the new stock segmentation control. `network_segmentation_default_deny` reads `k8s.networkpolicy_coverage.v1` and fails when any namespace has no default-deny all-pods NetworkPolicy. The bootstrap now uploads 64 stock controls, and an existing install gains the control on its next bootstrap run. To link the k8s connector's records to it, run `atlas-k8s run --netpol-control network_segmentation_default_deny`; the default `scf:NET-06` is stored as a free-form reference. The bundled SOC 2 crosswalk maps no criterion to `NET-06`, so SOC 2 coverage is unchanged.
