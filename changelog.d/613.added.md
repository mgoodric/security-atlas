- **feat(web): slice 613 — Settings control for the per-tenant control-bundle gate policy.** Slice 608 made the per-tenant control-bundle upload gate configurable (`tenants.bundle_gate_mode` ∈ `strict | advisory | mandatory_tests`, default `strict`) and exposed it on the admin-gated `PATCH /v1/tenants/{id}`, but deferred the web control (608 D5). This slice surfaces it: the Settings → Tenant section (admin/super_admin only, the same authority that gates the PATCH) gains a `<select>` of the three modes with a one-line explanation of each mode's effect (AC-3: strict = block red tests, allow no-tests; advisory = accept red with a warning; mandatory_tests = reject a no-tests bundle). Changing the control and Saving PATCHes `/v1/tenants/{id}` with `{bundle_gate_mode}` via the existing slice-144 BFF passthrough route (a verbatim body forwarder — no BFF or backend change), and the control reflects the persisted value the PATCH response returns. **READ-PATH JUDGMENT (D1):** `main` exposes no GET that returns a single tenant's `bundle_gate_mode` to the web layer (`/v1/me/tenants` is a JWT-claim directory of id/name/current; the admin tenants list omits the column), and adding one would be a backend change outside this web-only slice — so the control pre-selects the documented default (`strict`, which is exactly what the gate enforces for an unchanged tenant) and reflects the authoritative value on save, surfacing the pending-vs-persisted distinction honestly. The mode set + labels + AC-3 explanations + a fail-safe-toward-strict parser live in the new pure helper `app/(authed)/settings/gate-mode.ts` (vitest: 24 cases, 100% coverage, floored at 98%); a hermetic Playwright spec (`e2e/settings-gate-policy.spec.ts`) route-mocks the `/api/me/tenants` GET (deterministic current tenant) and the PATCH response (known mode) — it does NOT rely on the shared-DB seed for state (b219 lesson) — asserting the control renders the default, swaps explanations on change, PATCHes the chosen mode, and reflects the persisted value. **Anti-criteria (P0):** WEB-ONLY — no `internal/` Go change, no new backend endpoint or BFF route (608 owns the API). **Type: code** (JUDGMENT-light — the read-path call recorded with detection-tier in `docs/audit-log/613-web-bundle-gate-policy-toggle-decisions.md`).
