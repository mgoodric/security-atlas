- **feat(admin): organisation admins manage their own API keys, within their own authority (#2503).** A tenant admin, judged by its live roles, now reaches Admin › API keys and Settings › API tokens for its own tenant. It can issue, rotate and revoke ordinary keys. It cannot mint an `is_admin` or `is_approver` key, and it cannot rotate or revoke one a platform super-admin minted; each of these is a 403. A super-admin's behaviour is unchanged.
