- **fix(atlas): the server no longer hangs at exit when three or more background loops fail (#2770).** `cmd/atlas` collected goroutine errors in a channel with buffer 2 that ~17 loops sent to, and nothing read it until every loop returned; a third failure blocked its sender forever, so the process needed SIGKILL and printed none of the errors. Errors now go into a mutex-guarded collector that never blocks, and every collected error is printed before the exit-1.
