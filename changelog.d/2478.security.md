- **fix(policies): a policy whose linked controls are all retired can no longer be published, and only a canonical uuid counts as a person in approval checks (#2478).** Publish now needs at least one non-retired linked control in the tenant; a policy whose only links were retired after its last edit gets 422 (`ErrNoLiveLinkedControl`). An empty link list is still the 409 orphan block. Submit re-runs the create and draft-edit link check, so a draft linking a retired control gets 422 and stays a draft until the author fixes the link. Approve does not check links. A principal names a person only as a canonical 36-character lowercase uuid: the 32-hex, `{...}`, `urn:uuid:` and upper-case forms that `uuid.Parse` also accepts now name no user (`identity.UserID`), so a draft editor recorded in one of them is an unknown author.
