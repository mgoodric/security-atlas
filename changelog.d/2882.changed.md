- **feat(controls): warn on a bundle-test record without `evidence_kind` when the queries read two kinds (#2882).** Such a fixture record reaches every query in a test, while a live record without a kind reaches none of the kinded ones, so the case never tests the per-query kind split. `atlas-cli controls validate`, `atlas-cli controls test` and the upload gate's test report (`warnings`) now flag it; it does not fail the run. Stock bundles must set the kind on every such record, and `soc2_p4_2_retention_schedule` now ships tests. Upgrade note for tenant bundles (#2818 D6): a `manual_attested` or `manual_periodic` control with a query that declares an `evidence_kind` no longer has its attestations (`manual.attestation.v1`) read by that query. Declare `manual.attestation.v1` on a query, or leave the kind off, if it should read them.
