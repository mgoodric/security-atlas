- **fix(authz): a signed-in user with no role in the tenant gets no access, not grc_engineer (#2401).** Every login path (local, OIDC/PKCE, device grant) mints an empty role claim for a user with no `user_roles` row in the tenant, and that empty claim derived `grc_engineer`. So revoking a user's only role lasted only until their next login. A JWT session with an empty claim now derives nothing: its roles are the live `user_roles` rows alone, and with none every tenant route answers 403. Only `oauth_client:` machine tokens keep the old default. Upgrade note: before rolling out, run `scripts/dry-run-2401-roleless-users.sql` (read-only, counts only) to see how many active users per tenant have no role, and grant them one if they should keep access.
