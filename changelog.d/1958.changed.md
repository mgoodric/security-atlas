- **fix(control): an `external_refs`-only re-upload updates the control in place (#1958, follow-up to #1908 and #1737).** Since #1908 a description-only change to `control.yaml` kept the control id and version; adding or editing `external_refs` still superseded the control, which left owners, evidence, exceptions and links on the old version. A change confined to `description` and/or `external_refs` now updates the active row in place and records the prior manifest in `control_manifest_revisions`. Uploads also lock the active row (`SELECT … FOR UPDATE`), so two concurrent in-place uploads no longer both copy the same manifest and lose the first one's text. **Upgrade note:** a bundle re-uploaded with only new refs now keeps its control id and version instead of minting `version+1`.
