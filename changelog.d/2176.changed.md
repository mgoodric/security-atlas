- **feat(controls): list controls needing SCF re-anchoring, with a dashboard warning (#2176, follow-up to #1971).** `GET /v1/controls/needs-reanchoring` lists the tenant's active controls left on an anchor of an earlier SCF release that the #1971 rule flags for a person, each with its remap note. Pinned bundles (`scf_release`, or an anchor UUID) and controls the next boot re-binds are left out. Any role that can read controls can read the list. The dashboard shows a warning with the count and a link to `/controls/needs-reanchoring`. Once each control's bundle is re-uploaded on a current-release anchor, the warning clears.
