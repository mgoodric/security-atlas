- **feat(metrics): metric target changes are audited, and GRC engineers can set them (#2572).** `PUT /v1/metrics/{id}/target` writes a `me_audit_log` row (`metric_target_set`) in the same transaction as the change, with the acting user, the credential (`actor_principal`) and the before and after values. Admins and GRC engineers can now set a metric target, as they set a framework posture target; manual metric input stays admin-only. The target dialog stores a percent target on the metric's own scale: if the metric records percentage points (85) rather than fractions (0.85), the target is saved as typed, so the threshold badge compares like with like. Ratio metrics are entered as a percentage, as they are displayed. Migration `20261269000000_metric_target_audit` extends the action CHECK.
