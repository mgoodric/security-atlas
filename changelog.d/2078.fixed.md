- **fix(frameworkscope): a backdated scope activation can no longer rewrite a frozen audit period (#2078).** `PATCH /v1/framework-scopes/{id}/activate` returns 409 when `effective_from` is earlier than the latest frozen audit period's freeze on that framework version. Framework scopes now record `activated_at`, and a frozen period's SSP selects only a revision activated by its freeze, so re-exporting a frozen period gives the same exclusions after any later activation. Upgrade note: the migration backfills `activated_at` for existing activated and superseded revisions from their workflow-log activation entry, or from `LEAST(effective_from, updated_at)` for revisions activated before that log existed.
