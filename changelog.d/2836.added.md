- **feat(controls): the controls import's web upload maps columns before staging (#2836).** `/controls/imports` now reads the sheet first and shows each detected header with the control field it maps to (pre-filled from the platform's aliases, changeable), the unmapped columns and a preview of the first rows, using the mapping step the risk import shares (#2848). A sheet whose headers match no alias is offered with its fullest early row as the header and can be mapped and staged from the web; before, only the API and the CLI could import it. New API: `POST /v1/controls/imports/preview` reads an upload's header mapping and first rows without staging, and the upload accepts a repeatable `ignore_column=Header` to keep an alias-matched column unmapped.
