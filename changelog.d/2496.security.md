- **fix(authz): a signed-in user's roles come from their live role assignments only, never the role list baked into their session token (#2496).** A session whose token still said admin or grc_engineer kept control_owner reads and writes after every role was revoked, until the token expired. Now revoking a user's roles takes effect on their next request, and granting one back applies at once, with no re-login. Machine (client_credentials) tokens, API keys and super-admin are unchanged.
