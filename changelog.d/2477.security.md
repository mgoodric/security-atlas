- **fix(modules): module views close the gaps left after #2173 (#2477).** Activity now places an authorization decision by the request path it was made on, so a decision on a nested or `/v1/me` route of a hidden module (for example `/v1/me/acknowledgments` or `/v1/controls/{id}/policies` while Policies is hidden) is no longer listed. Rows recorded before the path was stored, and paths the module registry cannot place, still fall back to their resource type. A metric that measures a hidden module now answers 404 on `/v1/metrics/{id}/observations`, `/inputs` and `/target`, as its catalog entry already did. Combined views now apply feature switches as well as module switches. The gRPC API refuses ICS calendar feed tokens (keys whose only kind is `calendar.read.v1`) as unauthenticated on every RPC. Before this fix such a token could register and list connectors; evidence ingest already refused its records by kind. A key that has other kinds besides `calendar.read.v1` is unaffected.
