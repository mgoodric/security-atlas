- **fix(crosswalk): a crosswalk import that drops a mapping also retires the edge an SCF remap carried from it (#3065).** A carried edge (`crosswalk_source = scf-remap:<proposal>`) used to stay live in default coverage after the crosswalk dropped its source mapping. The import now follows the remap proposal back to the edge it wrote, retires the copy with it, and restores it if the mapping is listed again. This applies to every crosswalk import, on BYO installs and on installs that imported an SCF release upgrade. Installs that never had an SCF upgrade have no carried edges and are unchanged. `import-crosswalk` and `converge-crosswalks` print each carried edge they retire or restore.
