- **feat(connectors/confluence): the Confluence policy connector, end to end (#2856).** New binary `atlas-confluence run` reads every page with one label in one Confluence Cloud space, takes each page's Page Properties table as its policy metadata, converts the body to Markdown, and pushes the full set to `POST /v1/policies:sync` in one request with a `policy-sync` API key. It prints the per-page report (created, new version, taken over, unchanged, drift, skipped with reason, missing) and lists the macros each page uses that have no Markdown form. The Confluence credential stays with the connector. A run that can't read the whole labelled set, or finds no pages at all, pushes nothing and exits non-zero, so an outage never reads as pages disappearing. Schedule it yourself; daily is recommended. See `connectors/confluence/README.md`.
