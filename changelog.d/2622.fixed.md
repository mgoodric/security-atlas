- **fix(openapi): reflected response schemas follow encoding/json for self-encoding types, `,string` and embedded pointers (#2622).** A type that implements `json.Marshaler` or `encoding.TextMarshaler` is now documented only through an explicit mapping (`time.Time` as a date-time string, `uuid.UUID` as a uuid string, `json.RawMessage` as any value); any other one, such as `pgtype.*` or `net.IP`, fails generation instead of being documented by its Go kind (a UUID was an integer array). `[]byte` is a base64 string, a `,string` bool or number is a string, and an embedded `*Struct` is flattened with its fields optional. `ResponseSchemas` notes that handlers must allocate slices, since a nil slice encodes as `null`. The committed spec is unchanged.
