# #2298 — OIDC state: issued-at under the MAC, HKDF for the derived key

detection_tier_actual: manual_review
detection_tier_target: unit

Follow-ups from the security review of #2287 (#2177). A signed state never
expired on the server, and the derived state key was a `bearer.Hash` value.

## Decisions

| #   | Decision                                                                                                                                                                              | Why                                                                                                                                                                                                                                                                                                                                                  |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | `state = rand "." iat "." HMAC(k, rand, iat, tenant, idp, nonce)`, `iat` in decimal unix seconds. The MAC label moves to `atlas-oidc-state-v2`.                                       | The issue time is MAC'd like every other field. The new label means no v1 MAC can verify under the new field list.                                                                                                                                                                                                                                   |
| D2  | The callback checks the MAC with `hmac.Equal` first and parses `iat` only after it verifies.                                                                                          | No field of an unauthenticated state is trusted, iat included.                                                                                                                                                                                                                                                                                       |
| D3  | Refuse a state whose age exceeds `FlowCookieMaxAge` (10 min) + `StateClockSkew` (30 s), or whose `iat` is more than `StateClockSkew` in the future.                                   | Replicas' clocks differ slightly; 30 s is small next to the 10-minute window. Dispatcher call on the ticket.                                                                                                                                                                                                                                         |
| D4  | Anything other than exactly three dot-separated parts, an empty `rand` or `iat`, or a non-decimal `iat` is refused (`ErrStateMismatch`).                                              | Fail closed. The two-part pre-#2298 state is refused, not accepted without an age.                                                                                                                                                                                                                                                                   |
| D5  | Derived key: `hkdf.Key(SHA-256, BEARER_HASH_KEY, salt=nil, info="atlas-oidc-state-key-v2", 32)` from the standard library `crypto/hkdf` (module is Go 1.26).                          | See D6. Stdlib, so no new dependency.                                                                                                                                                                                                                                                                                                                |
| D6  | Extract-then-expand, not Expand alone over `BEARER_HASH_KEY`.                                                                                                                         | Expand alone with one output block is `HMAC(root, info \|\| 0x01)`, which is still `bearer.Hash` of a string. Extract keys the final HMAC with a pseudorandom key instead of the root, so the result is not `HMAC(root, x)` for any `x`. Deviates from the dispatcher's "Expand" wording to meet its "can no longer equal any `bearer.Hash` output". |
| D7  | `ATLAS_OIDC_STATE_KEY`, when set, is used as is; only the derived fallback changes.                                                                                                   | Scope of the ticket.                                                                                                                                                                                                                                                                                                                                 |
| D8  | Upgrade note: **OIDC logins in progress at deploy time fail once with a 400 and must restart.** Both the state format and, on deploys without `ATLAS_OIDC_STATE_KEY`, the key change. | A flow lives at most 10 minutes; the cost is one retry per user mid-login.                                                                                                                                                                                                                                                                           |
