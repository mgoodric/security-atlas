# #2087 — entity picker for controls, risks and policies: decisions

detection_tier_actual: none
detection_tier_target: none

| #   | Decision                                                                                                                                                                                     | Why                                                                                                                                                                                                                                                                                                                           |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | The multi-select (`EntityMultiPicker`) is an inline search box over a checkbox list, not a Base UI multiple combobox.                                                                        | The ticket asks to keep today's behaviour: search, checkboxes, the 0/50 counter. Both forms it replaces were checkbox lists. It shares the single picker's data layer (`useEntityOptions`) and option logic (`lib/entity-picker.ts`), so a kind is added in one place.                                                        |
| D2  | A 403 or 404 from a list reads "<Kind> are not available to you." in place, and the query is not retried.                                                                                    | 404 is what the module gate answers when the module is switched off (`internal/featureflag/modules.go`); 403 is a role that cannot read the list (#2390). Neither changes on retry. Any other failure still shows the load error.                                                                                             |
| D3  | The questionnaire citation picker is left as it is.                                                                                                                                          | It searches controls **and evidence** through `/api/search` and appends one citation per pick; evidence is not a kind this ticket adds. Moving only its control half onto this picker would split one "+ Cite" palette in two. It has no 0/50 counter today. Proposed as a follow-up: add an `evidence` kind, then absorb it. |
| D4  | The old test ids survive where specs used them (`risks-create-control-multi-select`, `action-plan-risks`, `action-plan-controls`); the one rename is the risk form's `-filter` to `-search`. | The picker derives every test id from one `testId`, so the forms keep their prefixes and the existing specs keep reading them.                                                                                                                                                                                                |
| D5  | Controls search their bundle id through a new `keywords` field on `EntityOption`, not shown in the list.                                                                                     | The risk form's picker searched title, SCF code, family and bundle; the shared option shows the first three, and `keywords` keeps the fourth searchable.                                                                                                                                                                      |
