# #1742 — historical evidence import: build-time decisions log

detection_tier_actual: manual_review
detection_tier_target: integration

Two integrity defects in the first head of PR #3044 were caught by the PR review (comment 7140611483), not by tests. Both belonged in the integration tier and are now pinned there:

- **B1.** A freeze racing an import could change the original frozen population without a revision.
- **B2.** An amendment could admit a record observed after the original `frozen_at`.

Every acceptance criterion is pinned by `internal/evidence/historicalimport/*integration_test.go` (real Postgres, RLS). Each load-bearing branch was mutated and observed failing before being restored:

- the past-skew lift;
- the revision-aware frozen read;
- the authz hydrator bypass;
- the Freeze lock;
- the concurrent-freeze refusal (B1). With it removed, revision 1 no longer replays: `replay revision 1 = bee5… , stored frozen_hash f583…`;
- the observed_at bound (B2).

## Proposed ISA / invariant #10 wording, for Matt to apply

`isa/ISA.md`, the glossary (currently lines 250-251):

```markdown
- **Audit period** — a window that can be frozen. Once frozen, its sample
  population stops moving, except through a recorded, hashed, reasoned freeze
  revision. The original freeze always replays, and a revision may add only
  evidence observed at or before the original `frozen_at`.
```

`isa/ISA.md`, C10 (currently lines 96-97):

```markdown
- C10 · Audit-period freezing. A frozen period draws samples only from evidence
  with `observed_at ≤ frozen_at` that was in the ledger at `frozen_at`, plus
  evidence a recorded, hashed, reasoned freeze revision added; a revision adds
  only evidence with `observed_at ≤` the original `frozen_at`, and the
  original freeze always replays. Live state continues independently.
```

`AGENTS.md`, constitutional invariant #10 (currently line 151):

```markdown
10. **Audit-period freezing.** When an AuditPeriod is frozen, sample populations draw only from evidence with `observed_at ≤ frozen_at` (and in the ledger at `frozen_at`). A frozen population changes only through a recorded, hashed, reasoned freeze revision; the original freeze always replays; and a revision may add only evidence with `observed_at ≤` the original `frozen_at`. Live state continues independently. (canvas §8.4, ADR 0003)
```
