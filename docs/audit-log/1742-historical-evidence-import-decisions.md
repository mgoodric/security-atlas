# #1742 — historical evidence import: build-time decisions log

detection_tier_actual: none
detection_tier_target: none

No defect surfaced during the work. Every acceptance criterion is pinned by
`internal/evidence/historicalimport/integration_test.go` (real Postgres, RLS),
and the two load-bearing branches (the past-skew lift, the revision-aware
frozen read) were each mutated and observed failing before being restored.

## Decisions

| #   | Decision                                                                                                                                                                                                                                                                                                      | Why                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | A freeze revision is an append-only row in `audit_period_freeze_revisions` (revision >= 2) that lists the evidence record ids it adds. Revision 1 is the original freeze on the `audit_periods` row, which is never rewritten.                                                                                | The ticket requires the original hash and population to stay recorded and replayable. Keeping revision 1 on the existing row needs no backfill and leaves every existing reader of `frozen_at` / `frozen_hash` unchanged. Listing the added ids, rather than moving the horizon, keeps the population exactly "original plus the batch": moving `ingested_at`'s horizon to the amendment time would also admit any record ingested between the freeze and the amendment with an `observed_at` before the freeze (a late connector push inside the 24h window, the MCP bypass of #1751). |
| D2  | Frozen reads take the added ids as an `amended_ids uuid[]` parameter and admit `(observed_at <= H AND ingested_at <= H) OR id = ANY(amended_ids)`. Every other predicate (control, window, kind) still applies. Callers resolve the ids from the period (or the population's period) in the same transaction. | Seven queries take a horizon, not a period id. A parameter keeps the queries period-agnostic as they are now. A nil array admits nothing extra, so a caller that does not pass it reads the original freeze exactly as before #1742.                                                                                                                                                                                                                                                                                                                                                    |
| D3  | Wired callers: period control state, population sample draws (`resolvePopulationEvidenceIDsFromRow`), the frozen evidence summary (count, list, and citation resolution), and the auditor authz hydrator (`EvidencePeriods`).                                                                                 | These are every frozen-population read. The as-of replay (`ListEvidenceForControlAsOf`) is a point-in-time ledger read, not a period read, and is unchanged: a replay of a date before the import still does not see the imported records, which is ISC-3.                                                                                                                                                                                                                                                                                                                              |
| D4  | The revision hash is the ADR 0003 hash with the evidence set = the original horizon's ids plus revisions 2..N's ids, and the control set = the tenant's current catalog.                                                                                                                                      | Same inputs a replay of revision 1 uses today (ADR 0003 takes the catalog at recompute time). A revision cannot recover the catalog as it stood at the original freeze; the ADR already accepts that for revision 1.                                                                                                                                                                                                                                                                                                                                                                    |
| D5  | Window membership for "falls inside a frozen period" is the UTC calendar day of `observed_at` within `[period_start, period_end]` (both DATE).                                                                                                                                                                | The period bounds are dates. UTC matches how every other date in the ledger is stored and compared.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| D6  | The import locks every period whose window overlaps the batch's date range `FOR UPDATE` before deciding open vs frozen.                                                                                                                                                                                       | Serialises the import against a freeze of the same period (the freeze's `UPDATE ... WHERE status = 'open'` waits), so the decision cannot be made on a row a concurrent freeze changes. The residual DB-clock vs app-clock gap on `frozen_at` is #3038 and out of scope.                                                                                                                                                                                                                                                                                                                |
| D7  | A named `--amend-frozen` period that is open, or that the batch has no records in, refuses the import (`invalid_amend_frozen`).                                                                                                                                                                               | An amendment is an explicit act on a frozen period. Silently ignoring a misnamed id would let an operator believe a period was amended when it was not.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| D8  | If every in-window record of a named period deduplicates (already in the ledger), no revision is cut.                                                                                                                                                                                                         | The population did not change, so a new revision would carry an identical evidence set and a new row in the audit trail for nothing.                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| D9  | A whole-batch refusal (frozen-period conflict, bad amend target) writes one `rejected_validation` audit row per record with the reason and the batch id. No new decision value.                                                                                                                               | The ticket asks that every rejected record is audited under its batch. Adding a decision token would change `evidence_audit_log_decision_chk` and every reader that maps decisions.                                                                                                                                                                                                                                                                                                                                                                                                     |
| D10 | The batch-level source is the `--source` flag (`source` in the API body), not a header line in the JSON Lines file.                                                                                                                                                                                           | The ticket allows "plus batch-level source"; a flag keeps every line in the file a plain push envelope, so the same file can be pushed or imported.                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| D11 | Admin is `authz.IsTenantAdmin` and not a system credential, enforced in the handler (before the body is read) and again in `historicalimport.Import`. OPA reads the route as an evidence write and admits grc_engineer and control_owner; the handler is the narrower layer (`handlerNarrower2428`).          | Routing the path to a dedicated OPA resource type would mean adding `import` to `transitionActions`, which changes the action of every path whose last segment is `import` (e.g. `/v1/mapping-overlays/import`). The narrower-handler entry is the established pattern (#2110, #2134, #2503).                                                                                                                                                                                                                                                                                           |
| D12 | `Service.WithPath` drops an import batch.                                                                                                                                                                                                                                                                     | Only the copy `ForHistoricalImport` returns may lift the past skew limit; a later path re-tag must not carry the lift to a live path.                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| D13 | OSCAL exports are not changed. Samples drawn after an amendment draw from the latest revision, so the AP/AR sample evidence follows it. The export's POA&M and excepted-evaluation reads are `control_evaluations` as of `frozen_at`, which never contained imported evidence and are unchanged.              | The export carries no freeze hash today, so there is no hash to switch to the revision.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| D14 | `manual.attestation` 1.3.0 pins `period_start` / `period_end` to `YYYY-MM-DD` with a `pattern` as well as `format: date`.                                                                                                                                                                                     | The registry does not assert `format` unless a schema sets `x-assert-format`, and setting it would also start asserting `supporting_uri`'s `format: uri`, a behaviour change over 1.2.0.                                                                                                                                                                                                                                                                                                                                                                                                |
